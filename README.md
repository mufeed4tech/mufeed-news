# Mufeed News

Mufeed News is a static news website demo built to showcase an editorial-style layout and design system. It includes a homepage with a breaking news ticker, top stories, a featured hero story, trending and weekly highlight sections, a set of full article pages covering Egyptian news topics in both English and Arabic, and a contact page. The site is fully static: there is no backend, build step, or database, and all content is hardcoded into the HTML files.

## Getting Started

No installation or build step is required.

1. Clone or download this repository.
2. Open `index.html` directly in a web browser, or
3. Open the project folder in VS Code and run it with the Live Server extension for local development with automatic reload.

## Tech Stack

HTML, CSS, and vanilla JavaScript.
